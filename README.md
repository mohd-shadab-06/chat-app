# chat-app

Overview

  This project is a real-time chat application designed to demonstrate full-stack development skills using Node.js, React, and WebSocket technology (Socket.IO). The application allows users to communicate in real time with features like user login, one to one messaging, and group chat. Here a user can share images and documents as well.

Features

  1. It provides real time messaging.
  2. User login & logout.
  3. Chat History.
  4. Search an existing user.
  5. Group creation for group chat.

Installation and Setup Prerequisites:

Node.js and npm installed on your system.

Basic understanding of React and Node.js.

Steps to Run Locally:

Clone the Repository:

git clone <repository_url>
cd real-time-chat-application

Backend Setup:

cd server
npm install
npm start

The backend will start running on http://localhost:3000 (default).

Frontend Setup:

cd ../client
npm install
npm start

The frontend will start running on http://localhost:5173 (default).

Access the Application:
Open http://localhost:3000 in your browser to access the chat application.
